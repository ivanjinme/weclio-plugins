# Repository Guidelines

This file is the top-level index for AI agents working in this repository.
Use it to load only the guidance relevant to the current task. Code and tests remain the source of truth for implementation details.

## Constitution

- Read `CONSTITUTION.md` for implementation, debugging, refactoring, review,
  or architecture/design discussion.
- Skip only for factual lookup tasks that require no code or design judgment.
